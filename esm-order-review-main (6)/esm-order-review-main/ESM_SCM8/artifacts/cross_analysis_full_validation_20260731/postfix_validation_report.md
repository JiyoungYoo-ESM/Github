# 교차분석 문제 개선 후 검증

## 판정: 계산·표시 수정 완료, 원천 중복 후보만 주의

2026-07-31 검증에서 발견된 화면 의미·경계값 문제를 수정했다.

## 수정 내용

1. `최대 성장 조합`은 0보다 큰 성장률 중 최댓값만 사용한다.
2. `최대 감소 조합`은 0보다 작은 성장률 중 최솟값만 사용한다.
3. 해당 부호의 조합이 없으면 각각 `성장 조합 없음`, `감소 조합 없음`을 표시한다.
4. 정적 데이터 채움률은 값이 0인지가 아니라 원천 행×열 조합의 존재 여부로 계산한다.
5. 매출과 반품이 상쇄되어 선택 합계가 0이면 비중을 0%로 오인 표시하지 않고 `-`와 계산 불가 안내를 표시한다.
6. 순합계가 0 또는 음수여도 금액·수량 합계 자체는 숨기지 않는다.
7. 화면뿐 아니라 즉시 PDF·저장 보고서에서도 0분모 비중을 `-`로 표시한다.

## 남은 주의사항

CMS 판매 원천에 안정적인 판매행 ID가 없어 완전 일치 중복 후보 약 0.17%를
진짜 중복인지 정상 반복인지 확정할 수 없는 문제는 화면 코드에서 해결할 수
없다. 원천 API가 인보이스 라인 ID 또는 판매행 고유 ID를 제공하면 별도
유일성 검사를 추가해야 한다.
