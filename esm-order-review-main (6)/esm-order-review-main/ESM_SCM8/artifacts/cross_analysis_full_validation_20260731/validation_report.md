# 교차분석 완전 정합성 검증 보고서

## 최종 판정: Needs revision

검증 기준일은 2026-07-31(KST)이다. 사용자 화면과 일치하는 H&B/PL 운영
스냅샷을 주 기준으로 사용하고, 해당 기간에서 비활성인 YTD는 같은 PL의
2025~2026 완료월 운영 스냅샷으로 추가 검증했다.

결정적 계산 경로는 통과했다. CMS 원천에서 필터·상품 마스터 조인·집계
큐브·프런트엔드 행렬까지 키, 매출액, 판매량, 성장률 불일치는 0건이다.
다만 원천 판매행 고유 ID가 없어 약 0.17%의 완전 일치 중복 후보를
진짜 중복으로 확정할 수 없고, 성장 카드의 `최대 성장`·`최대 감소`
라벨이 부호를 고려하지 않는 문제가 있어 모든 선택 경우를 신뢰 가능한
상태로 승인할 수는 없다.

## 발견된 문제

1. **High — 성장/감소 카드의 부호 의미 오류**

   유효값 전체의 최대값과 최소값을 사용한다. 모두 감소한 선택에서는
   가장 덜 감소한 값이 `최대 성장`, 모두 성장한 선택에서는 가장 적게
   성장한 값이 `최대 감소`로 표시된다. 실제 검증 view-cell에서 양수
   단일 선택 8,497건, 음수 단일 선택 20,621건, 0% 단일 선택 110건이
   이 잘못된 라벨 상태를 만들 수 있다.

2. **Medium — 원천 중복 여부 미확정**

   H&B 범위에는 완전 일치 중복 후보 63개 초과행, €61,599.03,
   분석매출의 0.169412%가 포함된다. YTD 보조 범위에는 1,234개 초과행,
   €555,492.00, 0.172363%가 포함된다. 원천에 판매행 고유 ID 또는
   인보이스 라인 번호가 없어 자동 제거 또는 정상 반복 판정이 불가능하다.

3. **Medium — 0값의 데이터 채움 의미**

   정적 매출·수량이 0이면 실제 원천 조합이 있어도 미채움으로 계산한다.
   YTD 보조 정적 큐브에서 순매출 0인 실제 셀 1건이 확인됐다.

4. **Medium — 순합계 0의 비중 표시**

   양수와 반품이 상쇄되어 선택 합계가 0이면 모든 비중이 0%로 표시된다.
   데이터가 없는 것이 아니므로 `비중 계산 불가` 상태가 더 정확하다.

## 필수 수정

1. `최대 성장`은 `value > 0` 중 최대, `최대 감소`는 `value < 0` 중
   최소만 사용한다. 해당 부호가 없으면 `성장 조합 없음` 또는
   `감소 조합 없음`으로 표시한다.
2. 데이터 채움률을 값의 0 여부가 아니라 집계 원천 조합의 존재 여부로
   계산한다.
3. 비중 분모가 0이면 모든 셀 0% 대신 `계산 불가` 상태를 반환한다.
4. CMS 판매 API에 안정적인 판매행 ID 또는 인보이스 라인 번호를 추가하고
   중복 후보의 유일성 검사를 자동화한다.
