## Metric definitions

- **재고공백 일수**: 양수 공백 행에서 표시된 입고예정일과 재고소진일의 달력일 차이.
- **화면 설명식 부족수량**: `ceil(재고공백 일수 × 일평균 판매량)`.
- **표시 부족수량**: 내보내기 파일의 `부족수량` 값. 현재 구현은 긴급보충수량 또는 별도 부족수량이 있으면 설명식보다 우선한다.
- **최근 3개월 SKU 집중도**: 선언된 조회 기간 안의 SKU별 판매수량·판매금액 집계.
- **발주 전/후 금액**: 숨김 계산 시트의 SKU별 수량 × 단가를 합산한 KRW 금액.

## Chart decision

이번 감사는 추세나 분포 탐색보다 정확한 합계 대조, 예외 건수, 계산 정의의 일치 여부가 핵심이다. 대부분의 결과는 소스가 연결된 표로 제시한다. 다만 핵심 결함인 부족수량 30건의 표시 합계와 화면 설명식 합계는 차이의 규모를 즉시 파악할 수 있도록 단일 비교 막대 차트를 사용하고, 정확한 값은 표와 본문에 함께 남겼다.

## Limitations

- 두 Excel 내보내기의 생성일이 서로 다르므로 동일 시점의 SKU 단위 교차 조인은 수행하지 않았다.
- 라이브 API·DB를 같은 스냅샷으로 다시 호출하지 않았으며, 사용자가 내려받은 최신 로컬 내보내기와 코드 경계값을 검증했다.
- 전체 프런트엔드 `npm test` 묶음은 발주분석과 무관한 `cross-analysis-matrix.test.mjs` 장기 실행으로 완료되지 않았다. 타입 검사, 프로덕션 빌드, UI 회귀 및 관련 개별 테스트는 통과했다.
- 재고공백 부족수량의 30건 불일치는 데이터 오류일 수도 있고 의도된 발주모델 우선값일 수도 있다. 다만 현재 화면/내보내기 설명과 수치가 서로 다른 것은 확정적이다.
