1. 발주

Quantitative

1-1. 데이터 입력

판매·재고·미입고·운송 데이터는 API로 자동 연동됩니다. 계산에 쓸 기준값만 확인하고 분석을 시작하세요.

이렇게 사용하세요

  1. 분석 기준일을 확인합니다. 기본값은 오늘 — 보통 그대로 두면 됩니다.
  2. 적용 환율을 확인합니다. 선택한 법인의 통화 대 KRW 환율이 자동 조회되며(예: 폴란드는 EUR/KRW), 재조회 버튼으로 갱신할 수 있습니다. 특정 환율로 계산하고 싶을 때만 직접 수정합니다(수정하면 '수동 환율'로 표시).
  3. 안전재고 개월수를 확인합니다. 기본값 3개월이며, 팀 방침에 따라 직접 설정할 수 있습니다.
  4. 운송 리드타임을 확인합니다. 법인마다 실제 운송 조건에 맞는 기본값이 설정되며, 예를 들어 폴란드는 해운 70 · 항공 15 · 철송 30 · 트럭 30일입니다.
  5. 우측 분석 실행 패널의 ▶ 분석 시작을 누릅니다. 누르는 순간 최신 데이터를 조회해 모든 발주 화면에 반영됩니다.
가장 흔한 실수 — 값만 바꾸고 '분석 시작'을 안 누르는 것. 기준값은 버튼을 눌러야 반영됩니다.

항목설명

1-2. 발주 분석

발주가 필요한 상품과 필요 수량을 자동 계산해 보여주는, 발주 업무의 메인 화면입니다. '발주 추천 SKU'와 '재고 공백' 두 개의 보기가 있습니다.

매주 이 순서대로 (약 5분)

  1. 1-1 데이터 입력에서 기준값 확인 → 분석 시작
  2. 발주 추천 SKU 보기에서 상단 카드로 이번 주 규모 파악 → 표에서 빨간 숫자(발주필요수량)와 상태(긴급/주의) 확인
  3. 미입고 해소 전/후 버튼을 눌러보며 "새로 발주할지, 이미 주문한 물량 납기를 당길지" 판단 (아래 판단 기준 참고)
  4. 재고 공백 보기로 전환해 결품(품절) 위험 상품 확인
  5. 발주할 상품 체크 → 엑셀 내보내기 → 기존 발주 절차 진행

MOI란? "지금 재고로 몇 달 버틸 수 있나"입니다. 재고 ÷ 월평균 판매량. 1.5개월 미만이면 위험 신호로 봅니다. (예: MOI 0.5 = 보름치밖에 안 남음)

SKU 테이블 컬럼 — 처음 보는 분을 위한 읽기 순서

알아두세요 — '미입고 해소 전 / 해소 후' 토글에 따라 보이는 컬럼이 다릅니다. '해소 후'는 요약형(상품코드·SKU·브랜드·해소 후 재고·3개월 판매량·현지 MOI·발주필요수량·발주필요금액), '해소 전'은 상세형(여기에 미입고 수량·운송중 수량·판단 근거·발주 상태가 더 붙음)입니다.
컬럼이렇게 읽으세요
상품코드상품을 식별하는 코드 (예: JSMSM03-SRAEU)
SKU / 브랜드상품명과 소속 브랜드

3개월 판매량최근 3개월간 팔린 수량 — 판매 속도의 근거

발주필요수량빨간 숫자. 목표 재고(3개월치)를 채우려면 더 필요한 수량 — 이 화면의 핵심
발주필요금액발주필요수량을 상품 단가와 환율로 원화 환산한 금액

운송중 수량배·비행기에 실려 현지로 오고 있는 수량 ('해소 전' 보기에서 노출)
판단 근거왜 발주 대상인지 자동 설명 (예: "현지 재고가 목표 대비 부족 · MOI 15일(0.48개월) · 발주 29,980개 필요 · 운송중 44,888개")
발주 상태긴급 = 재고가 안전선 아래, 즉시 발주 검토 · 주의 = 여유 없음, 발주 검토

한국 창고에 대기 중인 EU 창고 재고는 발주 엑셀(내보내기)에 함께 담깁니다. 웹 표에서는 가로 스크롤로 확인할 수 있습니다.

판단 기준 — 미입고 해소 전 / 해소 후

왜 이 버튼이 중요한가? 이미 주문해 둔 물량(미입고)이 곧 들어온다면 새로 발주할 필요가 없을 수 있기 때문입니다. '해소 전'은 미입고를 못 받는다고 가정한 필요량, '해소 후'는 전부 받는다고 가정한 필요량입니다.
  • 미입고가 발주필요수량보다 많다 → 이미 주문한 것만 와도 충분. 브랜드에 납기 독촉(푸시), 신규 발주는 보류
  • 미입고가 발주필요수량보다 적다 → 다 들어와도 부족. 신규 발주 진행

재고 공백 보기 — 품절 위험 점검

재고 공백이란? 재고가 바닥나는 날(소진 예정)보다 다음 입고(ETA·도착 예정일)가 늦으면, 그 사이에 팔 물건이 없는 기간이 생깁니다. 이 기간이 '공백', 그동안 못 파는 수량이 '부족 수량'입니다.
  1. 상단 카드로 전체 규모를 확인합니다 (아래 표 참고).
  2. 표는 공백 일수가 긴 순으로 정렬되어 있습니다. 위에서부터 처리하세요.
  3. 공백이 긴 상품 → 항공 전환·납기 푸시 검토. ETA 미확인 상품 → 입고 일정 자체가 없는 것이니 물류 담당자에게 먼저 확인.

2. 분석

Insight

판매 데이터를 국가·브랜드·상품·시즌 관점으로 보여줍니다. 성분 관점은 현재 준비 중입니다. 아무리 눌러도 데이터가 바뀌지 않으니 자유롭게 탐색하세요.

사이드바 구성 — '차원별'은 국가 → 브랜드 → 제품군 → SKU 순서로 한 가지 기준을 깊게 보는 화면입니다. '심화'는 시즌 캘린더 → 교차분석 → 브랜드 리포트 순서로 시즌 계획과 복합 분석·보고서 기능을 제공합니다. 성분 탭은 준비 중으로 별도 비활성화되어 있습니다.
즐겨찾기(★) — 메뉴 항목의 별표를 누르면 자주 쓰는 화면을 사이드바 맨 위에 고정해둘 수 있습니다. 편의 기능이며 데이터에는 영향이 없습니다.

2-1. 데이터 입력

분석에 쓸 기간과 기준을 정하고 분석을 시작하는 화면입니다.

이렇게 사용하세요

  1. CMS 연결 상태와 마지막 동기화 시각을 확인합니다 (예: 판매이력 184,302건 · 상품 1,284종).
  2. 기간을 고릅니다 — 프리셋(최근 1년 등) 또는 직접 입력. 처음이라면 '최근 1년'을 추천합니다.
  3. 분석 기준(판매수량/판매금액)을 고릅니다.
  4. 분석 시작을 누릅니다 — 눌러야 모든 분석 화면에 반영됩니다.
항목설명
장기 판매이력국가·브랜드·상품별 판매수량·판매금액 (자동 조회)
상품목록상품코드·상품명·브랜드·기능구분 (자동 조회)
기간 선택직접 선택은 최대 24개월. 12개월 미만이면 연간 시즌성 판단에 제한

2-2. 국가

"어느 국가에서 가장 잘 팔리나?" — 권역·국가를 선택하면 그 나라의 강한 브랜드·상품·시즌성이 함께 나옵니다.

이렇게 사용하세요

  1. 상단에서 전체 규모(전체 매출·매출 발생 국가 수·브랜드 수·SKU 수)를 봅니다.
  2. 권역별 매출 비중 → 국가별 판매 순위를 봅니다. 초록/빨강 %는 전월 대비(MoM) 증감입니다.
  3. 국가를 클릭하면 오른쪽에 상세 패널이 열립니다.
  4. 아래 국가별 성장 변화(전월 대비 / 전년 동기 대비)에서 성장·감소 상위 국가를 확인합니다.

선택 국가 상세 패널

  • 매출·점유율·월 최고 매출(가장 잘 팔린 달)
  • 상위 브랜드 미리보기 (교차분석으로 바로가기)
  • Top 5 카테고리 (그 나라에서 강한 기능군)
  • 상위 SKU 목록 (판매금액 기준)
  • 국가 시즌성 — 월별 매출 비중 라인 차트와 피크월

2-3. 브랜드

"이 브랜드는 어떤 상품에 매출이 몰리나? 어느 국가에서 강한가?" — 브랜드 미팅 준비의 출발점입니다.

이렇게 사용하세요

  1. 왼쪽 순위에서 브랜드를 클릭합니다.
  2. 오른쪽 패널을 위에서 아래로 읽습니다: 매출·점유율 → SKU 집중도 → 국가 분포 → 제품군 구성 → 상위 SKU.
  3. 아래 브랜드별 성장 변화(MoM/YoY)와 브랜드 월별 시즌성 비교(최대 6개 브랜드)에서 추이를 봅니다.
  4. 미팅용 자료가 필요하면 브랜드 리포트(→ 2-8)를 이용합니다.

선택 브랜드 상세 패널

항목설명
매출 / 판매수량 / 매출 발생 SKU / 판매 국가선택 기간 규모
점유율전체 브랜드 매출 대비 이 브랜드의 비중
SKU 집중도상위 상품별 매출 비중(TOP 5 합계 % 병기). 집중도가 높으면 그 상품 품절 = 브랜드 매출 하락
국가 분포국가별 매출 비중 (TOP 5)
제품군·라인 구성비썬케어·스킨케어 등 라인별 매출 비중
상위 SKU 상세상품별 매출·판매수량
브랜드별 성장 변화전월 대비(MoM)/전년 동기 대비(YoY) 성장·감소 상위. YoY는 전년 데이터가 없으면 '산출 불가'(오류 아님)
브랜드 월별 시즌성 비교1~12월 매출 비중 흐름을 최대 6개 브랜드까지 겹쳐 비교, 최고월 표시

2-4. 제품군

"같은 제품군에서 어떤 브랜드·제품이 잘 팔리나? 우리 제품은 이 제품군에서 몇 위인가?" — 기능구분 1·2로 묶은 제품군별 순위와 제품군 내 SKU 경쟁 위치를 봅니다.

이렇게 사용하세요

  1. 상단 판매량 / 매출액 토글로 기준 지표를 고릅니다. (매출 열람 권한이 없으면 판매량으로 고정됩니다.)
  2. 왼쪽 제품군 전체 목록에서 제품군을 고릅니다. 순위 그대로 나열되고 검색도 되므로 원하는 제품군(예: 13위)을 바로 찾을 수 있습니다.
  3. 오른쪽에 선택 제품군의 SKU 순위가 즉시 갱신됩니다. 브랜드와 무관하게 그 제품군 안에서 잘 팔리는 SKU를 봅니다.
  4. 전체 보기로 SKU 전체 순위(검색·페이지)를 펼쳐 우리 제품의 순위와 1위와의 격차를 확인합니다.

화면 구성

항목설명
전체 제품군기능구분 1·2 조합으로 묶인 제품군 수 (예: 썬케어 > 크림)
선택 제품군 / 전체 비중현재 선택한 제품군과 그 제품군이 전체(판매량 또는 매출액)에서 차지하는 비중
구성 SKU / 브랜드선택 제품군에 포함된 SKU 수와 브랜드 수
제품군 전체 목록제품군을 순위·비중 바로 나열. 검색으로 특정 제품군을 바로 선택
제품군 내 SKU 순위선택 제품군 안에서 SKU를 순위·비중·피크월·브랜드와 함께 표시
리포트로 내보내기제품군 전체 순위와 선택 제품군 SKU 순위를 PDF로 출력(워터마크 포함)
왜 개별 경쟁 제품을 자동으로 매칭하지 않나 — 같은 제품군이라도 용량·제형·가격대·리뉴얼 여부가 달라 "무엇과 비교할지" 기준을 세우기 어렵습니다. 그래서 제품군 전체 순위를 펼쳐 사용자가 직접 위치를 확인하는 방식을 씁니다.
숫자를 볼 때 알아둘 것 — 리뉴얼 전후 제품은 새 SKU 코드가 생기면 별도 항목으로 집계됩니다(대표 제품으로 통합하지 않음). 기능구분이 미분류인 상품이 많으면 순위가 실제와 다를 수 있으니 데이터 점검에서 정리하세요.

2-5. SKU

"이 상품은 언제·어디서 잘 팔리나? 언제 준비해야 하나?" 탭 2개(월별 판매 비중 / 발주·국가 정보)로 구성됩니다.

이렇게 사용하세요

  1. 전체 브랜드 드롭다운 또는 SKU 검색으로 상품을 선택합니다. 잘 모르겠으면 판매 TOP 10 SKU 카드 중 하나를 눌러보세요.
  2. 월별 판매 비중 탭 — 어느 달에 매출이 몰리는지(피크월) 봅니다.
  3. 발주·국가 정보 탭 — 매출 순위·판매수량·피크 준비월·국가별 판매 분포를 봅니다.

SKU 상세 카드 — 월별 판매 비중 탭

항목설명
기능구분·카테고리상품이 속한 기능군 (예: 썬케어·크림)
피크월 / 매출 비중매출 비중이 가장 높은 달(빨간색) / 그 달의 비중(%)
월별 판매 비중 차트1~12월 매출 비중(%) 라인 차트

SKU 상세 카드 — 발주·국가 정보 탭

항목설명
매출 순위선택 범위(전체 브랜드 또는 특정 브랜드) 내 매출 기준 순위
판매수량 / 매출선택 기간 전체 판매수량 / 매출 금액 (원화는 참고 환산값)
판매 국가이 상품이 판매된 국가 수
피크 준비월빨간색. 피크월에서 고정 3개월을 거꾸로 계산한 준비 시작월

국가별 판매 분포매출 비중 상위 5개국 바 차트(%)

2-6. 시즌 캘린더

"지금 어떤 기능군이 피크인가? 다음 피크는 언제인가?" — 시즌 상품을 미리 발주하기 위한 화면입니다.

이렇게 사용하세요

  1. 상단 카드 3개를 봅니다 — 현재월 수요 상위 기능군 / 다가오는 피크와 D-day / 그 다음 피크. "지금 발주 권장"이 떠 있으면 배송 기간을 고려할 때 지금이 발주 타이밍이라는 뜻입니다.
  2. 히트맵을 봅니다 — 행은 기능군, 열은 1~12월. 진한 빨강일수록 그 달 수요 지수가 높습니다. 오른쪽 끝에 피크월이 표시됩니다.
  3. 행 왼쪽의 > 를 누르면 하위 기능군(예: 페이스메이크업 → 쿠션·파운데이션…)이 펼쳐집니다.
어떻게 활용하나 — 월별 수요 지수(완료월 기준 집계)와 피크월을 보고 피크가 오기 전에 미리 발주할 시점을 판단합니다. 발주 수량 자체는 발주 분석(안전재고 3개월 기준)에서 계산되며, 이 화면은 발주 타이밍을 잡는 참고용입니다.

2-7. 교차분석

"국가×브랜드처럼 두 가지 기준을 한 표에서 동시에 보고 싶을 때" 씁니다.

이렇게 사용하세요

  1. 상단에서 조합을 고릅니다 — 국가×브랜드 · 국가×SKU · 브랜드×SKU. 성분 기반 조합은 성분 탭과 함께 현재 비활성화되어 있습니다.
  2. 보기 기준을 고릅니다 — 매출액/판매량/YoY/MoM, 금액/비중.
  3. 국가 추가 / 브랜드 추가로 비교 대상을 넣고, 태그의 ×로 뺍니다. 행·열 각각 최대 6개까지 선택할 수 있습니다.
  4. 표 위 요약 카드에서 최강 조합·상위 3 조합 집중도·선택 범위 합계(또는 조합 수)·데이터 채움률을 한눈에 확인할 수 있습니다.
  5. 셀 색이 진할수록 규모가 큽니다. 필요하면 엑셀 내보내기.

2-8. 브랜드 리포트

"브랜드 미팅 전 보고서를 클릭 한 번으로." — 기존 3~4시간 걸리던 작업이 즉시 완성됩니다.

이렇게 사용하세요

  1. 오른쪽 위 드롭다운에서 브랜드를 선택합니다.
  2. 상단 4지표(총매출·YoY·점유율·판매 SKU)와 함께 총 8개 섹션이 자동 조립됩니다: ① 브랜드 전체 판매 현황 → ② 주요 판매 국가 → ③ 상위 SKU → ④ SKU 집중도 → ⑤ 월별 피크 → ⑥ 성분·라인 트렌드 → ⑦ 현재 재고·MOI → ⑧ 향후 발주 참고.
  3. PDF 내보내기를 누르면 바로 저장됩니다.

YoY가 '산출 불가'로 나오면 전년 동기간 데이터가 없다는 뜻입니다. 오류가 아닙니다.

2-9. 성분 (준비 중)

현재 비활성화 — 성분 탭은 데이터 정합성 보강을 위해 준비 중 상태로 비활성화되어 있습니다. 현재는 메뉴에서 선택하거나 성분 분석 기능을 사용할 수 없습니다.

"어떤 성분이 뜨고 있나? 어느 국가·브랜드에서 강한가?" — 흩어진 성분 표기(센텔라·시카·병풀…)를 하나로 묶어 성분 단위로 봅니다.

활성화 후 제공 예정

  1. 성분 순위·성장 탭 — 성분별 매출·성장률·주요 국가·주요 브랜드를 봅니다.
  2. 오른쪽 성분 × 국가 / 성분 × 브랜드 미리보기에서 교차분석으로 바로 넘어갈 수 있습니다.
  3. 성분 매칭 탭 — 어떤 키워드가 어떤 표준 성분명으로 묶였는지 확인합니다 (예: 히알·히알루·히아루 → 히알루론산).
숫자를 볼 때 알아둘 것 — SKU별 성분 정보를 알려주는 마스터 데이터가 없어서, 상품명에 성분 이름이 들어간 상품만 텍스트로 감지해 집계합니다. '성분 미매칭 SKU'가 많을수록 순위가 실제와 다를 수 있으니, 미매칭이 많이 쌓여 있으면 데이터 점검에서 정리부터 하세요.

3. 데이터 점검

Quality

데이터 진단

분류가 비어 있는 상품을 정리하는 화면입니다. 미분류를 줄일수록 발주·분석의 모든 숫자가 정확해집니다. 주 1회 5분이면 충분합니다.

안내 — CMS 시즌/성분 분석 결과를 기준으로 점검 항목이 자동 집계됩니다. 보정값을 저장한 뒤 다시 분석하면 결과에 반영됩니다.

이렇게 사용하세요

  1. 분류 필요 SKU — 판매는 되는데 카테고리가 없는 상품입니다. 대분류·중분류를 드롭다운에서 고르고 선택값 저장. 목록이 판매량 순이니 위에서부터 처리하세요.
  2. 성분 미매칭 SKU — '확인 필요'를 눌러 자동 추정된 성분을 확인하고 승인합니다.
  3. 권역 기준 확인 — 권역이 없는 국가가 있으면 지정합니다. (0건이면 할 일 없음)
  4. 저장한 값은 다음 분석부터 반영됩니다 — 분석 탭에서 '분석 시작'을 다시 눌러주세요.
