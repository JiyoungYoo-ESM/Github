자주 묻는 질문을 먼저 확인해 보세요. 원하는 답을 찾지 못하시면 문의하기로 접수할 수 있습니다.

데이터 입력CMS 판매이력·재고 데이터가 자동으로 안 불러와져요.

데이터 입력 화면에서 CMS 연동 상태와 마지막 동기화 시각을 먼저 확인하세요. 시각이 오래됐다면 새로고침 후 다시 시도하고, 계속 안 되면 문의하기로 접수해주세요. 이 웹은 엑셀 업로드가 필요 없고, 판매·재고·미입고·운송 데이터가 CMS API로 자동 연동됩니다.

데이터 입력다른 법인이 안 보여요.

로그인하신 팀 계정에 허용된 법인만 보이는 게 정상입니다. 계정은 개인별이 아니라 소속 팀 단위로 발급되며, 팀마다 조회 권한이 다르게 부여됩니다(예: BM팀 계정은 전체 법인, 베트남 담당 팀 계정은 베트남만). 필요한 법인이 안 보이면 권한이 잘못 설정된 것일 수 있으니 문의하기로 알려주세요.

데이터 입력이 웹은 특정 법인(예: 유럽)에서만 쓸 수 있는 건가요?

아니요. 이 웹은 실리콘투 그룹 중 7개 법인(폴란드·영국·미국·두바이·멕시코·말레이시아·베트남)을 대상으로 하고, 화면 구성·계산 로직·용어는 7개 법인 모두 동일하게 적용됩니다. 화면에 보이는 구체적인 숫자(EUR/KRW, 해운 70일 등)는 법인마다 다르며(이 문서의 예시는 폴란드 기준), 법인을 선택하면 그 법인의 통화·리드타임·Site 값이 자동으로 표시됩니다. 법인별 Site 값은 상세 가이드 0장을 참고하세요.

데이터 입력적용 환율이 이상해요. 특정 환율로 고정하고 싶어요.

환율은 선택한 법인의 통화 대 KRW 기준으로 자동 조회됩니다(예: 폴란드는 EUR/KRW이며, 법인마다 해당 통화로 자동 표시됩니다). 재조회 버튼으로 최신값을 다시 받아올 수 있고, 특정 환율로 계산하고 싶을 때는 값을 직접 수정하면 되며 수정하는 즉시 화면에 '수동 환율'로 표시됩니다.

데이터 입력안전재고 개월수를 바꿀 수 있나요?

네. 기본값은 3개월이며, 팀 방침에 따라 직접 설정할 수 있습니다. 발주필요수량·MOI 위험 기준 등 발주 계산 전반에 이 값이 쓰이므로, 바꾸기 전에 팀 내에서 먼저 합의해주세요.

데이터 입력운송 리드타임 기본값을 수정해도 되나요?

네. 법인마다 실제 운송 조건(출발지·도착지·거리)이 다르기 때문에 리드타임 기본값도 법인별로 따로 설정됩니다(예: 폴란드는 해운 70·항공 15·철송 30·트럭 30일). 실제 운송 계약 조건이 바뀌면 그에 맞게 수정하면 되고, 이 값은 도착 예정일(ETA) 계산과 운송수단 추천에 그대로 쓰이니 실제 소요일과 차이가 크면 발주 분석 결과도 함께 달라집니다.

데이터 입력값을 바꿨는데 화면이 그대로예요.

기준값은 '분석 시작'을 눌러야 반영됩니다. 발주 쪽과 분석 쪽 데이터 입력은 각각 따로 있고, 각각 '분석 시작'을 눌러야 그 화면들에 반영됩니다.

데이터 입력'발주'와 '분석'에 데이터 입력 화면이 왜 두 개예요?

목적이 다릅니다. 발주 쪽 데이터 입력은 발주 계산에 쓰는 기준값(기준일·환율·안전재고 개월수·리드타임)을 정하는 화면이고, 분석 쪽 데이터 입력은 국가·브랜드·SKU 등 인사이트 화면에 쓸 조회 기간과 집계 기준(판매수량/판매금액)을 정하는 화면입니다.

데이터 입력분석 기간을 3년으로 잡고 싶어요.

직접 선택은 최대 24개월입니다. 프리셋(최근 1년/2025년/2024년) 중에서 고를 수도 있고, 시즌성 판단은 최근 1년(12개월) 이상을 권장합니다. 12개월 미만으로 잡으면 연간 시즌 판단에 제한이 생깁니다.

데이터 입력판매이력은 언제부터 조회할 수 있나요?

분석용 장기 판매이력은 2024년 4월부터 현재까지 조회할 수 있습니다. 다만 발주 분석에서 쓰는 '3개월 판매량'은 항상 최근 3개월 실적만 봅니다.

데이터 입력데이터가 하나도 안 나와요(0건).

① 좌측 상단 법인이 올바르게 선택돼 있는지 확인 ② 데이터 입력 화면에서 CMS 연동 상태가 정상인지 확인 ③ 분석 시작을 다시 눌러보세요. 그래도 안 되면 문의하기로 접수해주세요.

데이터 입력상품목록에 카테고리(기능구분)가 없는 상품은 어떻게 되나요?

분석 화면(시즌 캘린더, 제품군 구성비 등)의 집계에서 빠집니다. 데이터 점검 > 데이터 진단의 '분류 필요 SKU'에서 대분류·중분류를 채우면 다음 분석부터 반영됩니다.

데이터 입력MOI나 소진 예정일이 '—'로 나와요.

최근 3개월 판매가 0인 상품입니다. 계산 대상에서 제외되는 정상 동작이며 오류가 아닙니다.

데이터 입력신제품처럼 판매 이력이 없는 SKU는 발주를 어떻게 계산하나요?

이 시스템은 최근 3개월 판매량을 기준으로 계산하기 때문에, 판매 이력이 없는 신제품은 자동으로 계산해주지 못합니다(MOI·발주필요수량이 '—'로 나오는 게 정상입니다). 신제품 발주는 상품마다 사정이 달라 시스템이 판단할 수 없는 영역이라, 담당자 재량으로 결정해주세요.

데이터 입력재조회 버튼은 언제 눌러야 하나요?

환율처럼 실시간성이 필요한 값을 최신으로 다시 받아오고 싶을 때 누릅니다. 분석 시작을 누르는 시점에도 최신 데이터가 조회되니, 평소에는 분석 시작만 눌러도 충분합니다.

데이터 입력이 웹에서 값을 잘못 눌러도 괜찮나요?

네. 데이터 입력 화면의 모든 항목은 조회·설정용이라 실수로 눌러도 재고나 발주가 실제로 실행되지 않습니다. 실제 발주는 엑셀 내보내기 후 별도 절차에서만 진행됩니다.

발주분석MOI가 뭔가요? 왜 1.5개월이 기준인가요?

MOI(Month of Inventory)는 "지금 재고로 몇 달 버틸 수 있나"를 뜻합니다. (현재고 + 운송중) ÷ 월평균 판매량으로 계산하며, 1.5개월 미만이면 위험 신호로 표시됩니다. 화면에서는 "15일 (0.48개월)"처럼 일·개월을 함께 보여줍니다.

발주분석발주분석의 '3개월 판매량'에 이번 달(진행 중인 달)도 포함되나요?

포함 여부와 무관하게, 분석 기준일로부터 정확히 3개월 전까지의 판매량을 봅니다. 시즌 캘린더처럼 '완료된 월만 반영'하는 방식과는 다른 계산이니 헷갈리지 마세요.

발주분석발주필요수량은 어떻게 계산되나요?

안전재고(월평균 판매량 × 안전재고 개월수, 기본 3개월) − (현재고 + 운송중)입니다. 이 값이 마이너스가 나오면 화면에는 0으로 표시됩니다(발주 불필요라는 뜻).

발주분석'미입고 해소 전/후' 버튼은 뭔가요? 언제 어떤 걸 봐야 하나요?

'해소 전'은 미입고 물량이 하나도 안 들어온다고 가정한 필요량, '해소 후'는 미입고가 전부 들어온다고 가정한 필요량입니다. 미입고가 발주필요수량보다 많으면 신규 발주 대신 브랜드에 납기 독촉(푸시)을, 적으면 신규 발주를 진행하는 판단 기준으로 씁니다.

발주분석'발주 상태'의 긴급/주의는 어떤 기준인가요?

보유 재고(현재고+운송중)가 안전재고보다 적으면 '긴급', 안전재고의 1.5배 미만이면 '주의', 그 외에는 정상입니다.

발주분석재고 공백이 뭔가요?

재고가 바닥나는 날(소진 예정)보다 다음 입고(최초 ETA)가 늦을 때, 그 사이에 팔 물건이 없는 기간을 말합니다. 공백 일수 = 최초 ETA − 소진 예정일, 부족 수량 = 공백 일수 × 판매 속도로 계산합니다.

발주분석ETA 미확인 SKU가 많아요.

운송 데이터에 출고일이나 운송수단 정보가 비어 있어 도착일을 계산할 수 없는 상품입니다. 보완 전까지는 '입고 없음'으로 보수적으로 계산되니, 물류 담당자에게 원천 데이터 보완을 요청해주세요.

발주분석엑셀 내보내기 파일에는 뭐가 들어있나요?

ESM_order_review 엑셀에는 발주(메인 실행 탭) · 재고 ETA(날짜별 입고 그리드) · 보고서(브랜드 조회) · 입고예정(월별 입고 스케줄) · 확인필요(미입고 ETA·운송 ETA·입력 오류·운송수단 오류 점검) 5개 시트가 들어있습니다. 웹 화면과 동일한 로직으로 계산됩니다.

발주분석엑셀에 _입력파일현황처럼 밑줄(_)로 시작하는 시트들은 뭔가요?

다른 시트의 계산·드롭다운에 쓰이는 내부 참고용 헬퍼 시트입니다. 직접 볼 필요는 없고, 지우거나 값을 바꾸면 다른 시트의 계산이 깨질 수 있으니 그대로 두세요.

발주분석엑셀 '보고서' 시트에서 브랜드를 검색하면 뭐가 나오나요?

검색한 브랜드(또는 '전체')를 기준으로 총 발주 필요수량과 총 발주금액(EUR/KRW)이 자동으로 다시 계산됩니다. 미입고가 전혀 안 들어온다고 가정한 값과, 전부 들어온다고 가정한 값('미입고 해소 후') 두 버전을 함께 보여줍니다.

발주분석엑셀 상단의 파라미터 표(안전재고 개월수·리드타임 등) 숫자는 엑셀에서 바꿀 수 있나요?

아니요, 읽기전용입니다. 이 값은 엑셀을 내보낼 때 웹 데이터 입력 화면에서 설정해둔 값이 그대로 찍히는 것이라, 바꾸려면 웹에서 값을 바꾸고 다시 내보내야 합니다.

발주분석엑셀의 '운송수단 추천'은 어떤 기준으로 정해지나요?

재고가 고갈되기까지 남은 날수를 리드타임 단계와 비교합니다. 고갈까지 항공 리드타임(15일) 이내면 '① 항공 긴급', 철송 리드타임(30일) 이내면 '② 항공', 해운 리드타임(70일) 이내면 '③ 철송', 그보다 여유 있으면 '④ 해운 가능'입니다. 안전재고를 이미 충족하면 '● 발주불필요'로 표시됩니다.

발주분석성수기(피크월)엔 발주 수량이 자동으로 늘어나나요?

아니요. 현재 발주 수량은 안전재고 개월수(기본 3개월) 고정 기준으로만 계산되고, 시즌 배율은 자동으로 곱해지지 않습니다. 시즌 캘린더 화면에서 피크 타이밍을 참고해 리드타임만큼 미리 발주하는 방식으로 대응해주세요.

발주분석발주 상태가 '긴급'인데 실제 창고엔 재고가 있어요.

CMS 동기화가 오래됐을 가능성이 높으니 데이터 입력에서 재분석해보세요. 계속 그렇다면 안전재고 개월수가 실제 팀 방침보다 너무 높게 설정돼 있는지 확인해주세요.

발주분석EU 창고 재고는 웹 표에 왜 안 보이나요?

발주 추천 SKU 표에서는 가로 스크롤로 확인할 수 있고, 엑셀 내보내기 결과물에는 별도 컬럼으로 포함돼 있습니다. EU 창고 재고는 현지로 보내기 전 한국 창고에 대기 중인 수량입니다.

발주분석발주 분석 결과가 어제 본 것과 달라요.

발주 분석은 '분석 시작'을 누른 시점의 데이터로 고정됩니다. 그 사이 CMS 데이터(판매·재고·미입고·운송)가 갱신됐다면 재분석 시 결과도 달라집니다. 상단의 '분석 실행' 시각을 확인해보세요.

발주분석표시 기준(정렬 기준)을 바꿀 수 있나요?

네, 발주필요금액·공백 일수 등 여러 기준으로 정렬을 바꿀 수 있고, 브랜드 필터로 특정 브랜드만 볼 수도 있습니다.

발주분석'발주 추천 SKU'와 '재고 공백'은 뭐가 다른가요?

발주 추천 SKU는 "지금 얼마나 더 발주해야 하나"를 보여주는 발주 관점이고, 재고 공백은 "언제 품절이 나서 못 파는 기간이 생기나"를 보여주는 품절 위험 관점입니다. 같은 데이터를 다른 각도로 봅니다.

발주분석여기서 체크하고 엑셀로 내보내면 발주가 실제로 나가나요?

아니요. 이 화면의 모든 버튼은 조회·저장용입니다. 실제 발주는 엑셀 내보내기 후 기존 발주 절차(구매팀 승인 등)에서만 진행됩니다.

발주분석시스템이 추천한 발주 수량과 다르게 발주해도 되나요?

네, 그래도 됩니다. 발주필요수량은 어디까지나 판단 기준점을 제시하는 보조 도구이며, 실제 발주는 브랜드 상황·재고 정책 등을 가장 잘 아는 담당자가 최종 판단합니다. 반드시 이 수량대로 발주해야 하는 건 아닙니다.

발주분석여러 담당자가 같은 SKU를 중복으로 발주 처리할 위험이 있나요?

아니요. 담당자마다 맡고 있는 브랜드가 서로 달라서 실제로 겹칠 일이 없습니다.

발주분석발주필요수량이 갑자기 크게 늘었어요. 오류인가요?

먼저 판매(3개월)이 갑자기 늘지 않았는지, 안전재고 개월수나 환율 설정을 최근에 바꾸지 않았는지 확인해보세요. 원인을 못 찾겠으면 문의하기로 접수해주시면 확인해드립니다.

발주분석소진 예정일은 어떻게 계산되나요?

오늘 날짜에 (현재 재고 ÷ 하루 판매량)을 더해서 구합니다. 하루 판매량은 월평균 판매량 ÷ 30입니다. 예를 들어 재고 150개, 하루 판매량 3.3개면 약 45일 후이고, 오늘이 7월 7일이면 8월 21일쯤 바닥나는 것으로 계산됩니다.

발주분석발주필요금액은 어떻게 계산되나요?

발주필요수량 × 상품 단가(법인 통화) × 환율입니다. 예를 들어 150개 × 10(EUR) × 환율 1,750원이면 약 263만 원입니다.

발주분석ETA(도착 예정일)는 어떻게 계산되나요?

출고일 + 리드타임입니다. 리드타임은 운송 기록의 비고에서 해운·항공·철송·트럭킹 단어를 자동으로 찾아 그 법인의 기본값을 적용합니다(예: 폴란드는 해운 70·항공 15·철송 30·트럭 30일). 출고일이나 운송수단 정보가 비어 있으면 'ETA 미확인'으로 표시됩니다.

권한·계정새로 입사했는데 계정이 필요해요.

계정이 이미 있는 팀에 합류하는 거라면 별도로 새로 만들 필요 없이, 소속 팀의 로그인 정보를 팀 내에서 전달받아 쓰면 됩니다. 아직 계정이 없는 새로운 팀이라면 문의하기로 접수해주세요.

권한·계정우리 팀이 조회할 수 있는 법인·범위를 바꾸고 싶어요.

조회 권한(법인 범위)은 팀 계정 단위로 부여되며, 변경은 SCM팀 내부에서 관리합니다. 문의하기로 요청 사유를 적어 접수해주세요.

권한·계정로그인이 안 돼요 / 비밀번호를 잊었어요.

문의하기로 접수해주시면 담당자가 확인 후 도와드립니다. 계정이 팀 단위로 공유되므로, 비밀번호를 바꾸면 같은 팀 동료도 새 비밀번호로 다시 로그인해야 한다는 점을 함께 안내해주세요.

권한·계정퇴사자·부서이동자가 있으면 계정을 어떻게 정리하나요?

계정 자체가 팀 단위라 퇴사자 개인 계정을 따로 지울 필요는 없지만, 보안을 위해 해당 팀의 비밀번호를 변경하는 걸 권장합니다. 부서 이동자는 새로 소속된 팀의 로그인 정보로 바꿔 쓰면 됩니다. 필요하면 문의하기로 알려주세요.

권한·계정제 계정에서는 왜 일부 법인만 보이나요?

계정은 개인별이 아니라 소속 팀 단위로 발급되며, 팀마다 담당 범위에 따라 권한이 다르게 부여됩니다. 예를 들어 BM팀 계정은 전체 법인을 조회할 수 있고, 베트남 담당 팀 계정은 베트남 법인만 조회할 수 있는 식입니다. 권한 범위가 실제와 다르면 문의하기로 알려주세요.

권한·계정브랜드별로도 조회 권한이 다르게 나뉘나요?

아니요. 조회 권한은 브랜드와는 무관하게 오직 법인 기준으로만 나뉩니다. 팀 계정에 허용된 법인이라면 그 법인에 속한 모든 브랜드를 볼 수 있습니다.

권한·계정계정 하나를 여러 명이 같이 써도 되나요?

네, 원래 그렇게 쓰는 구조입니다. 계정이 개인별이 아니라 팀 단위로 발급되기 때문에, 같은 팀 동료끼리 하나의 로그인 정보를 함께 쓰는 게 정상입니다.

권한·계정같은 팀 계정으로 여러 명이 동시에 로그인해도 되나요?

네, 문제없습니다. 같은 팀 동료끼리 동시에 로그인해서 각자 화면을 봐도 무방합니다. 로그인 세션은 따로 로그아웃하기 전까지 계속 유지됩니다.

권한·계정제가 볼 수 있는 화면/기능이 다른 팀원과 달라요.

같은 팀 계정으로 로그인했다면 보이는 화면·기능이 동일한 게 정상입니다(계정이 개인별이 아니라 팀 단위라서요). 다르게 보인다면 서로 다른 팀 계정으로 로그인된 것일 수 있으니 로그인 정보를 확인해보시고, 계속 다르면 문의하기로 접수해주세요.

권한·계정권한을 바꿔달라고 요청했는데 언제 반영되나요?

처리 소요 시간은 요청 건에 따라 다릅니다. 진행 상황은 상단 '처리현황' 탭에서 확인할 수 있습니다.

API 연동어떤 데이터가 CMS에서 자동으로 연동되나요?

발주 쪽은 SKO재고(현지 창고 재고·단가·최근 3개월 판매) · 미입고(PO 현황) · EU재고(한국 창고 대기 재고) · 운송(해상컨테이너 상세) 4종이, 분석 쪽은 판매이력(판매내역상세) · 상품목록(카테고리) 2종이 자동으로 들어옵니다. 선택한 법인 통화 대 KRW 환율(지금은 EUR/KRW)도 자동 조회됩니다.

API 연동이 데이터들은 CMS의 어느 리포트에서 오나요?

SKO재고는 Report > 재고 > 법인 현지 창고 재고 현황, 미입고는 Report > 재고 > 미입고 현황, EU재고는 Report > 재고 > EU 창고 재고 현황, 운송은 Report > 해상컨테이너 상세내역, 판매이력은 Report > 판매 > 판매내역상세, 상품목록은 CMS > 상품 > 상품목록입니다.

API 연동Site(법인)·창고 설정이 왜 중요한가요?

같은 리포트라도 Site·창고가 다르면 완전히 다른 물량을 가리킵니다. SKO재고는 법인마다 자기 Site 값(예: 폴란드는 SKO Sp. z o.o.)을 쓰고 창고는 공통으로 ALL입니다. 나머지(미입고·EU재고·운송)는 법인과 무관하게 Site (주)실리콘투(한국 본사)·창고 EU창고로 조회합니다. 다른 법인의 정확한 Site 표기는 화면상 표기와 공식 법인명이 다를 수 있어 상세 가이드 0장 매핑표(실제 화면 캡쳐 기준)를 참고하세요.

API 연동연동된 데이터를 웹에서 직접 수정할 수 있나요?

환율만 수동으로 덮어쓸 수 있습니다(수동 환율로 표시). 나머지 CMS 연동 데이터는 원본 그대로 표시되며 웹에서 직접 수정할 수 없습니다. 값이 잘못됐다면 CMS 원본 데이터를 먼저 확인해주세요.

API 연동모든 데이터가 어떻게 하나로 연결되나요?

상품코드로 연결됩니다. 판매·재고·미입고·운송·상품목록 모두 CMS 상품마스터의 상품코드를 그대로 쓰기 때문에, 데이터 소스마다 코드가 다르게 잡혀 매칭에 실패하는 경우는 없습니다.

API 연동CMS에서 데이터를 바꾸면 이 웹도 실시간으로 바뀌나요?

완전한 실시간은 아닙니다. 이 웹은 CMS와 준실시간으로 연동되며, CMS 원본 데이터가 반영되기까지 최대 4시간 정도 시차가 있을 수 있습니다. 여기에 더해 '분석 시작'을 누르는 순간 그 시점의 데이터로 화면이 고정되니, 최신 상태를 보려면 시차를 감안하고 다시 분석 시작을 눌러주세요.

API 연동연동이 갑자기 끊기거나 데이터가 안 들어오면 어떻게 되나요?

마지막으로 성공한 동기화 값이 화면에 남아 있습니다. 데이터 입력에서 다시 조회해보고, 계속 실패하면 문의하기로 접수해주세요.

API 연동웹에 나온 숫자가 CMS 원본과 다른 것 같아요.

Site·창고·상품구분·기간 필터 설정이 화면 계산 기준과 다르면 숫자가 달라질 수 있습니다. 특히 미입고·운송의 기간 필터(연초~현재)는 연도가 바뀌면 갱신이 필요합니다. 그래도 차이가 있으면 문의하기로 접수해주세요.

API 연동판매이력은 얼마나 오래된 데이터까지 연동되나요?

분석용 장기 판매이력은 2024년 4월부터 현재까지 조회 가능합니다. 발주 계산에 쓰는 판매 속도는 항상 최근 3개월만 봅니다.

API 연동외부 시스템(엑셀 자동화, BI 툴 등)에서 이 데이터를 API로 가져올 수 있나요?

현재 확인된 범위에서는 엑셀·PPT·HTML 내보내기만 지원하며, 별도의 외부 연동용 API 제공 여부는 확정된 내용이 없습니다. 필요하시면 문의하기로 요청해주세요.

기타시즌 캘린더의 월별 수요 지수는 어떻게 만들어지나요?

판매이력의 월별 판매를 상품목록의 기능구분1(대분류)·기능구분2(중분류)로 묶어 기능군별로 집계합니다. 완료된 월(부분·누락월 제외)만 반영하며, 카테고리가 없는 상품은 데이터 진단에서 분류해야 집계에 포함됩니다.

기타교차분석의 셀 색깔은 무슨 뜻인가요?

셀 색이 진할수록 그 조합(예: 국가×브랜드)의 매출·판매량 규모가 큽니다. 매출액/판매량/YoY/MoM, 금액/비중 기준을 바꿔가며 볼 수 있습니다.

기타교차분석에서 국가·브랜드 등을 왜 6개까지만 고를 수 있나요?

행·열 각각 최대 6개까지로 제한되어 있습니다. 그보다 많이 고르면 표 헤더가 여러 줄로 접히고 요약 카드의 조합명도 알아보기 어려워지기 때문입니다. 더 보고 싶은 대상이 있으면 태그의 ×로 기존 선택을 빼고 새로 추가해주세요. 표 위 요약 카드에서는 최강 조합·상위 3 조합 집중도·선택 범위 합계(또는 조합 수)·데이터 채움률을 바로 확인할 수 있습니다.

기타국가·브랜드 화면에 있던 '평균 MOI'가 안 보여요.

현재 화면 구성에서는 국가·브랜드 상세 패널에 평균 MOI를 표시하지 않습니다. 재고·MOI 관련 정보는 발주 분석이나 브랜드 리포트의 '현재 재고·MOI' 섹션에서 확인할 수 있습니다.

기타브랜드 리포트에는 어떤 내용이 들어있나요?

상단 4개 지표(총매출·YoY·점유율·판매 SKU)와 함께 ① 브랜드 전체 판매 현황 ② 주요 판매 국가 ③ 상위 SKU ④ SKU 집중도 ⑤ 월별 피크 ⑥ 성분·라인 트렌드 ⑦ 현재 재고·MOI ⑧ 향후 발주 참고, 총 8개 섹션이 자동으로 조립됩니다.

기타YoY(전년 동기 대비)가 '산출 불가'로 나와요.

전년 동기간 데이터가 없어서 나타나는 정상 동작입니다. 오류가 아닙니다.

기타엑셀 내보내기 파일이 깨져서 나와요.

엑셀 버전에 따라 한글 인코딩이 다르게 처리될 수 있습니다. Excel 2016 이상에서 다시 열어보시거나, 문의하기에 파일을 첨부해 보내주시면 확인해드립니다.

기타데이터 진단에서 분류를 안 하면 어떻게 되나요?

분류 필요 SKU(카테고리 미지정)는 시즌 캘린더·제품군 구성비 집계에서 빠지고, 성분 미매칭 SKU는 성분 순위 집계에서 빠지고, 권역이 없는 국가는 권역별 비중 집계에서 빠집니다. 급한 문제는 아니지만 방치할수록 분석 정확도가 떨어집니다.

기타MOI, MoM, YoY 같은 용어를 어디서 확인할 수 있나요?

사용설명서(웹게시용)와 상세 가이드(다운로드용) 맨 뒤 '용어 사전·FAQ'에 핵심 용어가 정리돼 있습니다. 화면 우측 상단에서 바로 이동할 수 있습니다.

기타계산 로직(공식)까지 자세히 알고 싶어요.

상세 가이드(다운로드용) 5장 '계산 로직'에 MOI·발주필요수량·재고 공백·운송수단 추천 등 모든 계산식과 예시 숫자가 정리돼 있습니다.

기타화면이 느려요 / 안 열려요.

새로고침을 먼저 시도해보고, 그래도 안 되면 브라우저 캐시를 지우거나 다른 브라우저로 열어보세요. 계속 문제가 있으면 문의하기로 화면 스크린샷과 함께 접수해주세요.

기타여러 명이 동시에 '분석 시작'을 눌러도 되나요?

네, 여러 사용자가 동시에 이용할 수 있습니다. 각자 분석 시작을 누른 시점의 데이터로 화면이 갱신되니, 팀원마다 보이는 숫자가 조금 다를 수 있다면 서로 분석 실행 시각을 확인해보세요.

기타문의하기로 접수하면 얼마나 걸리나요?

문의 유형과 우선순위에 따라 처리 기한이 다르게 잡힙니다. 접수 후에는 상단 '처리현황' 탭에서 담당자·접수일·처리기한·진행 상태(접수/처리중/완료/지연)를 확인할 수 있습니다.

기타발주 엑셀의 '확인필요' 시트와 웹의 '데이터 점검'은 같은 건가요?

완전히 같지는 않습니다. 웹의 '데이터 점검'은 분류 필요 SKU·성분 미매칭 SKU·권역 미지정 국가처럼 분석 정확도에 영향을 주는 항목을 정리하는 화면이고, 엑셀 내보내기의 '확인필요' 시트는 미입고 ETA·운송 ETA·입력 오류(오타·공란·수량/날짜 이상값)·운송수단 오류(해운/항공/철송/트럭 미인식값)처럼 발주 데이터 품질을 점검하는 시트입니다. 서로 연계되어 있지만 보는 대상이 다릅니다.

기타확인필요 시트의 '담당자판단·판단일시·담당자' 칸은 어떻게 쓰나요?

자동으로 채워지는 칸이 아니라, 검토한 사람이 직접 입력하는 영역입니다. 오타·공란·이상값 같은 항목은 시트가 자동으로 찾아서 보여주고, 그걸 확인한 뒤 어떻게 판단했는지(담당자판단)·언제(판단일시)·누가(담당자) 확인했는지를 직접 적어서 검토 기록을 남기는 용도입니다.

기타SKU 탭의 '피크 준비월'은 어떻게 계산되나요?

그 상품의 피크월(매출 비중이 가장 높은 달)에서 고정 3개월을 거꾸로 계산한 준비 시작월입니다. SKU별 리드타임을 반영한 값이 아니라, 리드타임·안전재고 개월수 등을 감안해 고정해둔 3개월입니다. 화면에는 빨간색으로 표시됩니다.

기타데이터 점검(데이터 진단)은 얼마나 자주 해야 하나요?

주 1회, 5분 정도면 충분합니다. 판매는 있는데 분류가 안 된 상품이 쌓일수록 시즌 캘린더·성분 순위·권역별 비중 같은 분석 화면의 정확도가 떨어지므로, 정기적으로 확인하는 것을 권장합니다.

기타데이터 점검에서 저장한 값은 언제 화면에 반영되나요?

저장 즉시 반영되지는 않습니다. 분석 탭에서 '분석 시작'을 다시 눌러야 그 다음 분석부터 반영됩니다.

기타권역(지역)은 어떻게 지정하나요? 왜 필요한가요?

데이터 점검의 '권역 기준 확인' 항목에서 권역이 없는 국가에 권역(예: 유럽 등)을 지정합니다. 국가 화면의 '권역별 매출 비중' 집계에 쓰이며, 권역이 없는 국가는 이 집계에서 빠집니다. 지정할 국가가 없으면(0건) 따로 할 일이 없습니다.

기타브랜드 리포트와 발주 분석의 재고·MOI 숫자가 똑같아요. 오류인가요?

오류가 아닙니다. 브랜드 리포트는 분석 데이터와 발주 데이터를 함께 쓰는 유일한 분석 화면이라, '현재 재고·MOI' 섹션은 발주 분석(1-2)과 같은 값을 그대로 가져와 보여줍니다. 재고 숫자가 이상하면 발주 쪽 데이터 입력에서 재분석 후 다시 확인해주세요.

기타문의하기에서 어떤 유형을 골라야 하나요?

데이터 오류(화면 숫자·계산이 이상할 때) / 기능 문의(사용법이나 특정 기능이 궁금할 때) / 권한·계정(계정 생성·권한 변경 관련) 중에서 고르면 됩니다. 스크린샷을 첨부하면 담당자가 더 빠르게 확인할 수 있습니다.

기타사이드바의 별표(★)는 뭔가요?

즐겨찾기 기능입니다. 메뉴 항목의 별표를 누르면 자주 쓰는 화면이 사이드바 맨 위에 고정돼서, 매번 하위 메뉴를 펼치지 않고 바로 이동할 수 있습니다. 편의 기능이라 데이터나 계산에는 영향이 없습니다.

기타'차원별'과 '심화'는 뭐가 다른가요?

'차원별'은 국가·브랜드·제품군·SKU 순서로 하나의 기준을 보는 화면입니다. '심화'는 시즌 캘린더·교차분석·브랜드 리포트 순서로 시즌 계획과 복합 분석·보고서 기능을 제공합니다. 성분 탭은 준비 중으로 별도 비활성화되어 있습니다.

기타어떤 브라우저에서 써야 하나요?

브라우저 제한은 없습니다. PC와 모바일 화면 모두 UI/UX가 대응되어 있어, 데스크톱·모바일 브라우저 어디서든 편하게 쓸 수 있습니다.

기타휴대폰으로도 쓸 수 있나요?

네, 모바일 화면에 맞춰 UI/UX가 대응되어 있어 주요 분석 화면과 엑셀 내보내기를 PC와 동일하게 이용할 수 있습니다. 다만 휴대폰도 회사 와이파이에 연결돼 있어야 접속됩니다(보안상 회사 IP에서만 접속 가능한 정책은 휴대폰도 동일하게 적용됩니다).

기타회사 밖(집·외부 와이파이)에서도 접속할 수 있나요?

아니요. 보안상 현재는 회사 IP에서만 접속할 수 있습니다. 휴대폰으로 접속할 때도 마찬가지로 회사 와이파이에 연결돼 있어야 하며, LTE/5G 같은 외부 데이터로는 접속되지 않습니다. 외부 접속이 꼭 필요한 경우 문의하기로 요청해주세요.

기타로그인하면 제일 먼저 어떤 화면이 나오나요?

소개 페이지가 열립니다. 상단 메뉴는 소개(이 웹을 만든 목적)·발주·분석·사용가이드로 구성되며, '사용가이드' 메뉴에서 사용설명서(웹게시용)와 상세 가이드(다운로드용) 두 가이드를 바로 확인할 수 있습니다.

기타제품군 탭은 뭘 보는 화면인가요?

기능구분1·2로 묶은 '제품군'(예: 썬케어 > 크림) 단위로 어떤 제품군이 잘 팔리는지 순위·비중을 보고, 특정 제품군을 고르면 그 안에서 브랜드와 무관하게 어떤 SKU가 잘 팔리는지 순위를 봅니다. 자사 제품이 해당 제품군에서 몇 위인지, 1위와 격차가 어느 정도인지 확인하는 용도입니다. 상단 토글로 판매량/매출액 기준을 바꿀 수 있고(매출 열람 권한이 없으면 판매량 고정), '리포트로 내보내기'로 PDF 출력도 됩니다.

기타제품군 순위·SKU 순위는 어떤 데이터로 만들어지나요?

판매이력의 SKU별 판매를 상품목록의 기능구분1 > 기능구분2 조합으로 묶어 집계합니다. 기능구분이 없는 상품은 '미분류'로 모이니, 데이터 점검에서 분류를 채울수록 순위가 정확해집니다. 리뉴얼 전후 제품은 새 SKU 코드가 생기면 하나로 통합되지 않고 별도 항목으로 잡힙니다(대표 제품 마더 코드가 아직 없기 때문).

기타제품군 탭에서 특정 제품의 경쟁 제품만 자동으로 보여줄 수는 없나요?

개별 제품을 1:1로 경쟁 제품과 자동 매칭하지는 않습니다. 같은 제품군이라도 용량·제형·가격대·리뉴얼 여부가 달라 '무엇과 비교할지' 기준을 세우기 어렵기 때문입니다. 대신 왼쪽 제품군 전체 목록에서(검색 가능) 원하는 제품군을 고르고, 그 안의 SKU 순위에서 자사 제품 위치를 직접 확인하는 방식입니다.

기타성분 탭이 비활성화되어 있어요.

성분 탭은 현재 데이터 정합성 보강을 위해 준비 중 상태로 비활성화되어 있습니다. 메뉴에서 '준비 중'으로 표시되며 지금은 선택하거나 성분 분석 기능을 사용할 수 없습니다. 기능이 준비되면 다시 활성화될 예정입니다.
