0-1. 접속과 계정 권한

계정마다 보이는 메뉴와 숫자가 다릅니다. "내 화면에 없는 메뉴"는 대부분 오류가 아니라 권한 설정입니다.

접속 조건 → 보안 정책상 회사 IP에서만 접속됩니다. 휴대폰으로 볼 때도 회사 와이파이에 연결돼 있어야 합니다. 모바일 화면에 맞춰 UI가 대응되어 있어 주요 분석 화면과 엑셀 내려받기를 PC와 동일하게 이용할 수 있습니다.
계정 발급 단위 → 계정은 개인별이 아니라 팀 단위로 발급되고(같은 팀은 로그인 정보를 함께 씀), 팀마다 조회 권한이 다르게 부여됩니다(예: BM팀 계정은 서비스 중인 전체 법인, 법인별 담당 팀 계정은 그 법인만).
권한이렇게 나타납니다
금액 조회권한이 없는 계정에서는 매출액·발주금액·단가·재고금액이 화면과 엑셀에서 숨겨집니다. 수량·비중·점유율·증감률·순위는 그대로 보입니다 → 발주분석 V3의 '총 발주금액' 카드와 '제안수량·금액'의 금액 줄이 사라지고, 비교 버튼도 '발주수량 비교'로 바뀌며, 엑셀의 단가·금액 열은 숨김 처리됩니다. 숫자가 사라진 것이 아니라 권한에 따라 가려진 것입니다.
발주 메뉴영업 전용 계정처럼 발주 접근이 없는 계정은 '발주' 그룹 메뉴 전체가 표시되지 않습니다(분석·데이터 점검만 사용).

1-1. 발주분석 V3

발주가 필요한 상품과 제안수량을 자동 계산해 SKU별로 검토하는 화면입니다. 분석 실행부터 엑셀 내려받기까지 이 화면 하나에서 끝납니다.

사이드바에 '발주분석'이 여러 개 보여요 → 왼쪽 메뉴에 데이터 입력 · 발주분석 V1 · 발주분석 V2 · 발주분석 V3(BETA) 가 함께 있습니다. 이 중 발주분석 V3가 현재 실제로 쓰는 최신 로직 화면입니다(BETA 표기는 화면이 계속 개선 중이라는 뜻일 뿐, 발주 판단 기준은 이미 V3입니다). 이 문서는 발주분석 V3 화면을 기준으로 설명합니다.

매주 이 순서대로 (약 5분)

  1. 좌측 상단에서 법인을 확인합니다. 화면 상단에 "분석 대상 법인명"으로 다시 표시됩니다.
  2. 우측 상단 발주 시나리오가 지금 회사 방침(쇼티지 방어 / 현금흐름 우선)과 맞는지 확인합니다.
  3. 분석 실행을 누릅니다 → 상태 배지가 '계산 중'으로 바뀌고, 끝나면 '계산 완료'가 되며 검토 목록이 채워집니다. 이미 결과가 있으면 버튼 이름이 새로 분석으로 바뀝니다.
  4. 상단 카드(발주 필요 SKU · 총 발주수량 · 총 발주금액 · 발주 보류·계산 차단 · 검토 완료)로 이번 주 규모를 파악합니다.
  5. 발주 검토 대상 표에서 상품을 확인하고, 검토하기를 눌러 SKU 계산 근거를 확인합니다.
  6. 각 SKU를 권고 유지 / 수량 수정 / 발주 보류 중 하나로 처리하며 검토 완료 건수를 채워갑니다. 여러 건은 체크 후 일괄 권고유지 · 일괄 보류로 한 번에 처리할 수 있습니다.
  7. 시나리오를 바꿔보고 싶다면 발주수량·금액 비교로 두 시나리오의 차이를 먼저 확인합니다.
  8. 처리가 끝나면 엑셀 내려받기 → 기존 발주 절차 진행.

검토하기 — SKU 계산 근거

표에서 검토하기를 누르면 그 SKU의 제안수량이 어떻게 나왔는지 단계별로 보여주는 패널이 열립니다. 지금 어떤 시나리오로 보고 있는지가 패널 상단에 표시되고, 이전 SKU · 다음 SKU로 검토 대기열을 그대로 넘길 수 있습니다.

  1. 이 SKU의 발주 제안 → 발주필요수량(원시)·발주필요금액과, 그 아래 계산 근거인 발주반영 총재고(IP)·목표재고(S). 제안수량이 0이면 "IP가 목표재고 이상이므로 발주필요수량은 0개입니다"로 이유를 먼저 알려줍니다.
  2. ① 향후 수요 예측 → 이 상품에 적용된 예측 엔진(SES · HOLT+감쇠 · Croston+SBA 중 하나) 배지와 설명, 향후 4주(28일) 예상 수요, 예측오차(RMSE), 예측에 사용한 계수. 계절 보정 적용 여부도 함께 표시됩니다.
  3. 계절지수 연결 (신설) → 이 상품이 기능구분1·2 기준인지 기능구분1 기준인지, 그리고 계산된 지수 연결 완료 / 기본값 1.0 연결 완료 / 연결 불가 중 어떤 상태인지 보여줍니다. 월별 지수도 펼쳐 볼 수 있습니다.
  4. ② 목표재고·정기발주 → L1(리드타임 수요) + L2(안전재고) + L3(발주주기 수요) 가 더해져 목표재고(S)가 되는 과정을 그대로 보여줍니다. L1+L2인 참고 ROP도 함께 표시되지만 발주 조건으로는 쓰지 않습니다(참고값). 마지막 줄은 목표재고(S) − 총재고(IP) = 제안수량 계산입니다.
  5. ③ 91일 판매(13주) → 최근 원본 실적과 계절 제거 후 곡선을 함께 보여주는 차트.
  6. ④ 자동 분류 근거 → ADI·CV²·추세 3개 지표가 어느 방향인지(낮음/보통/높음, 있음/없음)와 그 결과로 확정된 수요 패턴(안정형/추세형/간헐형/신규·이력부족).
계산에 사용한 값 자세히 보기 → 패널 하단을 펼치면 발주에 반영한 재고(현재 사용 가능한 재고 + 운송 중인 수량 + 미입고 수량 + 다른 거점에서 반영한 재고 − 추가 차감 수량 = 총재고 IP), 입고 소요기간과 검토 주기(리드타임·발주주기, 주말·공휴일 포함), 판매 예측에 반영한 기준(첫 판매일부터 경과일수, 계절지수 적용 여부)까지 숫자별로 확인할 수 있습니다.
재고 원천 확인 (신설) → 재고 원천의 특정 항목(① 미입고 / ② PNFM확정 / ③ 입고진행중 / ④ 입고완료 / 현지 가용 / 본사 법인창고 가용 / 오포 가용 / 운송중)이 비어 있어 0으로 적용됐거나 음수여서 계산을 차단한 경우, 그 사실을 항목별로 알려주는 섹션이 열립니다. 표에서는 검토 버튼이 재고확인으로 바뀌므로 눈에 띕니다.
미입고 수량은 최근 30일 PO만 반영합니다 (2026-09-04 변경) → 이전에는 연초부터의 미입고 잔량을 전부 입고예정으로 더했습니다. 그래서 오래된 PO 잔량이 계속 쌓여 총재고(IP)가 실제보다 커지고, 발주가 필요한 상품이 제안수량 0으로 판정되는 사례가 있었습니다. 이제 ① 미입고 수량만 PO 등록일 기준 최근 30일로 좁혀 반영하고, 이미 입고 통보되거나 입고가 진행 중인 ② PNFM확정·③ 입고진행중·④ 입고완료는 기간 제한 없이 그대로 반영합니다. 수량만 달라지며 상품이 목록에서 사라지지는 않습니다.
발주 전 확인 → 이 제안수량에는 박스 단위·최소 주문수량(MOQ)이 아직 반영되어 있지 않습니다. 화면에도 같은 경고가 표시되며, 실제 주문 전 별도 확인이 필요합니다.

패널 하단 권고 유지 · 수량 수정 · 발주 보류 세 버튼으로 이 SKU의 검토를 마칩니다. 처리한 건수만큼 상단 '검토 완료' 카드가 올라갑니다.

  1. 현재 적용 중인 계절지수 카드에서 적용 버전과 프로파일 수, 기본값 1.0 적용 건수를 확인합니다.
  2. 갱신을 실행하면 자동 검증이 돌아갑니다 — 24개월 범위, 1~12월 계수 존재, 계수 평균 1.0, 중복·법인 일치를 확인합니다.
  3. 통과하면 "자동 검증을 통과해 새 계절지수가 발주분석 V3에 적용되었습니다"로 즉시 활성화됩니다. 실패하면 "기존에 적용 중인 계절지수는 유지됩니다"로 안내되고 적용되지 않습니다.
  4. 기능구분별 계절지수 표에서 항목별 상태(V3 자동 적용 중 / 자동 적용 가능 / V3 적용 보류 / 계산 보류 → 기본값 1.0 적용)와 월별 상세를 확인합니다.
기본값 1.0이 뜻하는 것 → 계절지수 계산이 보류된 항목은 1~12월 모두 1.0을 적용합니다. 그 상품은 계절성에 의한 가감 없이 계산되며, 분류·판매이력 등 다른 계산 조건은 그대로 유지됩니다. 누락된 값을 임의의 지수로 대체하지는 않습니다.

기능구분2가 없거나 미분류인 상품에는 같은 법인의 기능구분1 계절지수를 적용합니다. 그마저 없으면 그 SKU는 발주분석 V3에서 '보류·차단'으로 분류됩니다 → 근본 해결은 데이터 점검에서 분류를 채우는 것입니다.

1-3. 데이터 입력 · 발주분석 V1·V2 · 재고 공백

발주분석 V3 이전 화면들입니다. 발주 판단 기준은 이미 V3이므로 참고용으로만 보시면 됩니다.

화면현재 역할
데이터 입력발주분석 V1·V2용 기준값 화면입니다 — 분석 기준일 · 안전재고 개월수 · 운송 리드타임을 확인하고 분석 시작을 누릅니다. 본사(스킨) 법인에서는 "본사 발주 분석은 제공하지 않습니다"로 안내됩니다. 발주분석 V3는 이 화면을 거치지 않습니다
발주분석 V1이전 로직 화면. 상단에 발주 추천 SKU / 재고 공백 두 개의 하위 탭이 있습니다
재고 공백발주분석 V1 화면의 하위 탭입니다. ETA 이전에 품절 가능성이 있는 SKU와 공백일·보완 수량을 봅니다 — 이전 문서의 "V3 화면에서 안 보인다"는 항목은 위치가 V1 하위 탭으로 유지된 것으로 확인됐습니다
발주분석 V2이전 로직 화면으로 남아있을 뿐 업무에는 쓰지 않습니다
V3에서 사라진 입력값 → 이전에는 데이터 입력 화면에서 안전재고 개월수와 이송 리드타임을 담당자가 직접 입력했습니다. V3부터는 이 값들이 상품등급·발주 시나리오·법인·운송수단별로 통계적으로 고정되어 있어 입력하지 않습니다. 대신 발주분석 V3 화면에서 발주 시나리오만 전사 단위로 선택합니다. 적용 환율도 화면에서 직접 입력하지 않고, 워크스페이스에 들어올 때 자동 조회한 환율을 원화 환산 참고값으로 사용합니다. 고정된 값 자체가 궁금하면 상세 가이드 4장을 참고하세요.

2. 분석

Insight

판매 데이터를 국가·브랜드·제품군·상품·시즌 관점으로 보여줍니다. 아무리 눌러도 데이터가 바뀌지 않으니 자유롭게 탐색하세요.

사이드바 구성 → '차원별'은 국가·브랜드·제품군·SKU 순서로 하나의 기준으로 보는 화면이고, '심화'는 시즌 캘린더·교차분석·브랜드 리포트 순서로 시즌 계획과 복합 분석·보고서 기능을 제공합니다. 성분 탭은 준비 중으로 별도 비활성화되어 있습니다.
금액이 안 보이는 계정 → 금액 조회 권한이 없으면 분석 화면의 매출액 대신 비중·점유율·증감률·순위·수량이 표시되고, 교차분석은 '금액' 대신 '비중' 기준으로 자동 전환됩니다. 화면이 고장난 것이 아닙니다(→ 0-1).

2-1. 데이터 입력

분석에 쓸 기간과 기준을 선택하고 분석을 시작하는 화면입니다.

이렇게 사용하세요

  1. CMS 연결 상태와 마지막 동기화 시각·건수를 확인합니다 (예: 판매이력 184,302건 · 상품 1,284종).
  2. 분석 시작일 · 분석 종료일을 고릅니다. 직접 선택은 최대 24개월이며, 12개월 미만이면 연간 시즌성 판단이 제한됩니다. 처음이라면 최근 1년을 추천합니다.
  3. 본사 법인은 분석 창고(전체 창고 / 오포창고 OPO)를 함께 고릅니다.
  4. 분석 시작을 누릅니다 → 완료되면 국가 분석 화면으로 자동 이동하고, 모든 분석 화면에 결과가 반영됩니다.
항목설명
장기 판매이력국가·브랜드·상품별 판매수량·판매금액 (자동 조회). 조회 가능 범위가 법인마다 다릅니다 — EU는 2024년 4월부터, 미주 현지판매는 2015년 11월 7일부터, 본사 장기 판매이력은 시작일 제한 없음
상품목록상품코드·상품명·브랜드·기능구분1/2 (자동 조회)
기간 선택한 번에 최대 24개월. 종료일은 오늘 이후로 선택할 수 없습니다
분석 창고본사 기준 전체 창고 또는 오포창고(OPO)
분석 요청이 몰릴 때 → "분석 요청이 접수되었습니다. 앞선 작업이 있으면 순서대로 시작합니다."가 표시됩니다. 기다리면 순서대로 처리되며, 분석 중단 버튼으로 멈출 수 있습니다(입력값은 유지됩니다). 기간이나 창고를 바꾸면 "새 기간으로 다시 분석을 시작해 주세요" 안내가 뜹니다.

2-2. 국가

"어느 국가에서 가장 잘 팔리나?" — 권역·국가를 선택하면 그 나라의 강한 브랜드·상품·시즌성이 함께 나옵니다.

이렇게 사용하세요

  1. 상단에서 전체 규모(전체 매출·매출 발생 국가 수·브랜드 수·SKU 수)를 봅니다.
  2. 권역별 매출 비중 → 국가별 판매 순위를 봅니다. %는 전월 대비(MoM) 증감입니다.
  3. 국가를 클릭하면 오른쪽에 상세 패널이 열립니다.
  4. 아래 국가별 성장 변화에서 성장·감소 상위 국가를 확인합니다. 감소 기여율로 어느 국가가 전체 감소를 끌어내렸는지 볼 수 있고, 판매가 끊긴 국가는 판매 소멸로 표시됩니다.
  5. 필요하면 리포트로 내보내기(PDF)로 화면 내용을 그대로 저장합니다.

선택 국가 상세 패널

  • 매출·점유율·월 최고 매출(가장 잘 팔린 달)
  • 상위 브랜드 미리보기 (교차분석으로 바로가기)
  • Top 5 카테고리 (그 나라에서 강한 기능군)
  • 상위 SKU TOP 5 목록
  • 국가 시즌성 → 월별 매출 비중 라인 차트와 피크월

이전 분석 결과를 그대로 보고 있는 경우 "구버전 결과 · 상위 SKU 기준(재분석 시 정확)" 안내가 표시됩니다 → 정확한 값이 필요하면 2-1에서 분석을 다시 실행하세요.

2-3. 브랜드

"이 브랜드는 어떤 상품에 매출이 몰리나? 어느 국가에서 강한가?" — 브랜드 미팅 준비의 출발점입니다.

이렇게 사용하세요

  1. 왼쪽 목록에서 브랜드를 클릭합니다.
  2. 오른쪽 패널을 위에서 아래로 읽습니다: 매출·점유율 → SKU 집중도 → 국가 분포 → 제품군·라인 구성비 → 상위 SKU.
  3. 아래에서 브랜드별 성장 변화(성장 상위·감소 상위)와 월별 판매 시즌성·브랜드별 월 매출 분포를 봅니다.
  4. 리포트로 내보내기(PDF)로 브랜드 기준 분석 리포트를 저장할 수 있습니다.

선택 브랜드 상세 패널

항목설명
매출 / 판매수량 / 매출 발생 SKU / 판매 국가선택 기간 규모
점유율전체 브랜드 매출 대비 이 브랜드의 비중
SKU 집중도상위 상품별 매출 비중(TOP 5 합계 % 병기). 집중도가 높으면 그 상품 품절 = 브랜드 매출 하락 → 발주 우선순위를 높일 것
국가 분포국가별 매출 비중 (TOP 5)
제품군·라인 구성비썬케어·스킨케어 등 라인별 매출 비중
상위 SKU 상세상품별 매출·판매수량. SKU 검색으로 좁힐 수 있습니다
브랜드별 성장 변화전월 대비(MoM)/전년 동기 대비(YoY) 성장·감소 상위. YoY는 전년 데이터가 없으면 '산출 불가'(오류 아님)

2-4. 제품군

신설 화면입니다. "어떤 제품군이 크고, 그 안에서 어떤 상품이 앞서 있나?" — 상품목록의 기능구분 1·2 기준으로 제품군 순위와 제품군 내 SKU 경쟁 위치를 봅니다.

이렇게 사용하세요

  1. 상단에서 전체 제품군 수와 매출액 / 판매량 기준을 고릅니다.
  2. 제품군 전체 목록에서 제품군을 선택합니다. 이름으로 제품군 검색도 됩니다.
  3. 선택 제품군의 전체 비중·구성 SKU와, 제품군 안에서의 제품군 내 비중으로 상품 순위를 확인합니다.
  4. 리포트로 내보내기(PDF)로 저장합니다.

기능구분이 비어 있는 상품은 이 화면 집계에서 빠지고 데이터 점검의 '분류 필요 SKU'에 나타납니다 → 분류를 채울수록 이 화면이 정확해집니다.

2-5. SKU

"이 상품은 언제·어디서 잘 팔리나? 언제 준비해야 하나?" 탭 2개(월별 추이 / 발주·국가 정보)로 구성됩니다.

이렇게 사용하세요

  1. 전체 브랜드 드롭다운 또는 상품명·SKU 코드 검색으로 상품을 선택합니다. 잘 모르겠으면 상단 판매 상위 SKU 카드 중 하나를 눌러보세요.
  2. 월별 추이 탭 → 어느 달에 매출이 몰리는지(피크월) 봅니다.
  3. 발주·국가 정보 탭 → 매출 순위·판매수량·발주 참고 정보·국가별 판매 분포를 봅니다.
  4. 매출표시 / 원화표시 토글로 현지 통화 기준과 원화 환산 기준을 바꿔 볼 수 있습니다.
항목설명
기능구분·카테고리상품이 속한 기능군 (예: 썬케어·크림)
피크월 / 매출 비중매출 비중이 가장 높은 달과 그 달의 비중(%)

매출 순위선택 범위(전체 브랜드 또는 특정 브랜드) 내 매출 기준 순위

국가별 판매 분포매출 비중 상위 국가 및 차트(%)

이 화면에는 현재고·재고 상태·리드타임 정보가 표시되지 않습니다. 재고 상태·제안수량이 필요하면 발주분석 V3(1-1)에서 확인하세요.

2-6. 시즌 캘린더

"지금 어떤 기능군이 피크인가? 다음 피크는 언제인가?" — 시즌 상품을 미리 발주하기 위한 화면입니다.

이렇게 사용하세요

  1. 상단 카드를 봅니다 → 지금이 피크월인 기능군 / 다가오는 피크 / 그 다음 피크. 발주 시점 여유와 함께 "지금 발주 권장"이 뜨면 배송 기간을 고려할 때 지금이 발주 타이밍이라는 뜻입니다.
  2. 히트맵을 봅니다 → 행은 기능군, 열은 1~12월. 진한 빨간색일수록 그 달 수요 지수가 높습니다. 오른쪽 끝에 피크월과 피크강도가 표시됩니다.
  3. 행 왼쪽의 > 를 누르면 하위 기능(기능2)이 펼쳐집니다.
  4. 판매금액 / 판매수량 기준을 바꿔 볼 수 있습니다.
어떻게 활용하나 → 월별 수요 지수(완료월 기준 집계)와 피크월을 보고 피크가 오기 전에 미리 발주할 시점을 판단합니다. 발주분석 V3에서는 계절지수가 예측에 이미 반영되어 성수기면 목표재고 자체가 커지지만, 그 반영은 SKU별 계산이라 이 화면처럼 기능군 전체를 한눈에 비교해주지는 않습니다. 이 화면은 여전히 "어느 기능군이 언제 뜨는지"를 넓게 보는 참고용입니다.

2-7. 교차분석

"국가×브랜드처럼 두 가지 기준을 한 표에서 동시에 보고 싶을 때" 씁니다.
