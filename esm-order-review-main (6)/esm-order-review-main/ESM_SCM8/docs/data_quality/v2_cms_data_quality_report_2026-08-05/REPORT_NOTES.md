- 기준일: 2026-08-05
- 대상: USA, PL 법인의 현지/본사 판매·재고, 미입고, 운송, 리드타임 API
- 데이터 보안: CMS 행 단위 원문과 SKU 목록은 저장하지 않고 집계 결과만 보존
- 재현 경로: `../v2_cms_data_quality.py` 및 `../v2_cms_data_quality_2026-08-05.ipynb`
- 보고서 구조 검증: 통과(17 blocks, 1 chart, 3 metric cards, 3 tables)
- 시각 검증: 휴대용 리더의 1440px 가로 오버플로 때문에 미완료. 자체 포함 HTML과 원본 아티팩트의 구조 일치는 정적으로 검증함

## 차트 맵

- `chart-excluded-qty`: USA·PL의 V1 Biz Type 정책 적용 시 제외 수량을 비교하는 세로 막대 차트

## 해석 원칙

- 완전 동일 행은 원전표 라인키를 확인하기 전 자동 중복 제거하지 않음
- 음수 매출·미입고는 임의로 부호를 바꾸거나 0으로 치환하지 않음
- 단가는 법인별 `stock_local.stock_ucost`를 사용하고, 0·누락은 금액 계산 불가로 분리
- 표준편차는 입고완료 Packing No 단위 유효 표본에서 계산
